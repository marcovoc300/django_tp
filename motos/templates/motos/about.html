Sobre el Proyecto

¡Hola! Soy Marco

Desarrollé esta plataforma impulsado por mi pasión por las **motos** y la libertad que brindan los **viajes** en dos ruedas.

El objetivo de este sitio es crear un espacio donde los entusiastas puedan catalogar, buscar y gestionar información sobre diferentes modelos de motocicletas.

Este trabajo es el proyecto final para el curso de Python y Django, donde apliqué conocimientos de bases de datos, vistas basadas en clases y sistemas de usuarios para crear una herramienta funcional y útil para la comunidad motera.
