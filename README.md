# Proyecto Final: MotoApp
**Alumno:** Marco Vocaturo

## Descripción:
Aplicación desarrollada en Django para la gestión de motocicletas. Permite registrar usuarios, iniciar sesión, ver un listado de motos (Pages), cargar nuevos modelos y realizar búsquedas por modelo.

## Tecnologías utilizadas:
* Python 3.x
* Django
* Bootstrap para el estilo visual

## Cómo ejecutarlo:
1. Instalar las librerías: `pip install -r requirements.txt`
2. Correr el servidor: `python manage.py runserver`
3. Acceder en el navegador a: `http://127.0.0.1:8000/`
